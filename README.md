I'm a CS undergraduate at ShanghaiTech. I enjoy building systems across the stack, from microarchitecture and RTL to FPGA integration, Linux bring-up, PCBs, firmware, and measurement.

## 🔭 What I'm building

- **[MIKU](https://github.com/TossACoinTAC/NSCSCC2026-MIKU):** a four-issue out-of-order LA32R SoC in SpinalHDL, running Linux 5.14 on Artix-7. I focus on CPU optimization, FPGA integration, and the software stack. [CPU](https://github.com/Maotechh/nscscc-cpu) · [Linux kernel](https://github.com/Maotechh/nscscc-linux-kernel)
- **AI inference hardware:** exploring LPU architecture and hardware/software co-design for local inference.
- **[iCE40 camera pipeline](https://github.com/Maotechh/icesugar-hm01b0):** open-source HM01B0 capture on iCE40UP5K, developed natively on NVIDIA DGX Spark ARM64.
